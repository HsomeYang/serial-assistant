## 技术约定（改代码前必读）

1. **增量解码**：串口按字节流到达，一个汉字可能被拆到两次 `data` 事件。必须用
   `decoder.decode(chunk, { stream: true })`，直接 `chunk.toString()` 必然出现半个汉字。
2. **原生模块**：`serialport` 13 使用 N-API，ABI 跨 Node / Electron 稳定，**不要**引入
   `electron-rebuild`。打包时必须保留 `node_modules/@serialport/bindings-cpp/prebuilds/`。
3. **`.vscodeignore` 的否定规则**：`!**/*.d.ts` 会把任意目录下的声明文件重新放行，
   包括不该打包的第三方目录，曾导致 14 MB 无关内容混入 vsix。放行范围要收紧为
   `!dist/src/**/*.d.ts`。
4. **激活事件**：状态栏在 `activate()` 中创建，`activationEvents` 必须包含
   `onStartupFinished`；只写 `onCommand` 会导致状态栏永不出现。
5. **文件编码**：所有 `.json` / `.md` / `.ts` 必须存为 UTF-8 无 BOM。用 GBK 存盘会让
   `package.json` 触发 `ERR_INVALID_PACKAGE_CONFIG`，扩展直接装不上。
6. **视图位置**：要出现在底部面板（与终端并列），必须用 `contributes.viewsContainers.panel`
   + `WebviewViewProvider`；`window.createWebviewPanel` 只会打开编辑器标签页，放不到底部面板。
7. **版本约束**：`@types/vscode` 不得低于 `engines.vscode`，否则 `vsce package` 直接报错。
